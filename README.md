# PCM_Simulation_Code

This repository contains R code for simulation studies using Promotion Time Cure Models (PTCMs) with machine learning methods for incidence modeling and Cox proportional hazards models for latency modeling.

## Methods Included

- Logistic Regression
-  Spline-based Modeling
- Decision Tree
- Support Vector Machine (SVM)
- Neural Networks
- XGBoost
- Random Forest


## Features

- EM algorithm estimation
- Weighted Breslow baseline survival estimation
- Bootstrap inference
- ROC/AUC evaluation
- Survival function estimation
- Simulation framework for cure models
